# ระบบเตือนภัยน้ำท่วม — เขตคลองสามวา กทม.

เว็บแอปแสดงระดับน้ำคลองรอบบ้าน และสถานะเตือนภัย 4 สี (ปกติ / เฝ้าระวัง / เตรียมพร้อม / น้ำกำลังมา)
ข้อมูลมาจาก สำนักการระบายน้ำ กทม. และ ThaiWater (สสน.)

> ⚠️ เป็นการประเมินจากข้อมูลทางการ **ไม่ใช่ประกาศทางการ** — ดูน้ำจริงหน้าบ้านประกอบเสมอ

## ใช้งานบนคอม

```bash
npm run fetch   # ดึงข้อมูลล่าสุด → public/data/latest.json
npm run serve   # เปิด http://localhost:5173
npm test        # ทดสอบตรรกะสถานะ
```

บนเว็บจริงไม่ต้องสั่งเอง: **cron-job.org** สั่ง GitHub Actions (`update.yml`) ทุก 15 นาที (ตั้งเวลาของ GitHub เองเป็นตัวสำรอง — GitHub มักข้ามรอบ)
จำลองแหล่งข้อมูลล่ม: `SKIP=bma,popnix,tw,rain,river,radar npm run fetch`

## การใช้งานจริง

- เว็บ: https://moszasa09-boop.github.io/flood-alert/ (ติดตั้งลงหน้าจอหลักได้)

  ยกระดับ/ลดระดับสถานะ · แดงเตือนซ้ำ 15 นาที · น้ำขึ้นเร็ว ≥ 3 ซม./ชม. · เกินตลิ่ง/กลับต่ำกว่าตลิ่ง ·
  ฝนจะตก (นับถอยหลัง) · เตือน 30 นาทีก่อนฝน · ฝนเริ่ม/ยังตก/หยุด · น้ำเหนือล้นลงมาถึงจังหวัดใหม่ · เขื่อนเปลี่ยนการปล่อยน้ำ · สรุปเช้า 07:00
  ส่งไม่ได้ → ลองใหม่ 3 ครั้ง แล้วเข้าคิวส่งรอบหน้า (≤ 3 ชม.) · ตัวระบบพัง → แจ้ง "⚠️ ระบบขัดข้อง"

- แท็บ: แผนผัง · ฝน · น้ำเหนือ · แผนที่ (เส้นทางน้ำ) · สรุป (Dashboard) · ข้อมูล — แท็บ "ไม้วัด" ถูกแทนด้วย "สรุป" ตามที่ผู้ใช้ขอ (4 ต.ค.)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/config.mjs` | พิกัดบ้าน, เกณฑ์เตือน, รายชื่อสถานีบนแผนผังสายน้ำ — **แก้ที่นี่ที่เดียว** |
| `src/sources/bma.mjs` | ดึงข้อมูล กทม. (JSON ทุกสถานี + กราฟย้อนหลังจากหน้าเว็บ) |
| `src/sources/thaiwater.mjs` | ดึงข้อมูล ThaiWater |
| `src/sources/popnix.mjs` | แหล่งสำรองข้อมูลคลอง กทม. ผ่าน POPNIX Flood (ใช้เมื่อเว็บ กทม. บล็อก เช่นบน GitHub Actions) — จับคู่สถานีด้วยพิกัด ≤ 200 ม. |
| `src/sources/openmeteo.mjs` | พยากรณ์ฝนรายวัน (ใช้ยกเป็นเหลืองเมื่อฝน ≥ 35 มม./วัน) |
| `src/status.mjs` | ตรรกะตัดสินสี (ทดสอบใน `test/`) |
| `public/rain.js`, `public/rain-core.js` | แท็บ "ฝน": เรดาร์ RainViewer สด + หากลุ่มฝนใกล้บ้าน + พยากรณ์รายชั่วโมง |
| `scripts/fetch.mjs` | รวมทุกอย่าง → เขียน `public/data/latest.json`, `history.json` (48 ชม.) |
| `public/` | เว็บแอป (HTML/CSS/JS ล้วน ไม่ต้อง build) |

## เกณฑ์สถานะ

ต่อสถานี (เทียบระดับน้ำกับตลิ่งฝั่งที่ต่ำกว่า, ประตูน้ำใช้น้ำด้านใน):
- 🔴 น้ำถึง/เกินตลิ่ง
- 🟠 เหลือ < 20 ซม. หรือ < 50 ซม. และขึ้น ≥ 2 ซม./ชม.
- 🟡 เหลือ < 50 ซม. หรือขึ้น ≥ 5 ซม./ชม.
- ⚪ ข้อมูลเก่ากว่า 90 นาที (กทม.) / 180 นาที (ThaiWater) → ไม่นำมาตัดสิน

สถานะรวม: ใช้คลองใกล้บ้าน (ค.พระยาสุเรนทร์ ถ.หนองระแหง ห่าง 1 กม.) เป็นหลัก
+ ยกระดับเมื่อน้ำเหนือ/ทางระบายใต้ใกล้ล้น · แดงต้องเจอ 2 รอบติดกัน · ไม่มีข้อมูลคลองใกล้บ้าน = "ข้อมูลไม่พอ" (ไม่ใช่เขียว)

## ความสดของข้อมูล (หน้าเว็บประเมินใหม่ทุกครั้งที่แสดง — `public/fresh.js`)

- คลอง: เก่ากว่า 90 นาที (กทม.) / 180 นาที (ThaiWater) → เทา ไม่นำมาตัดสิน · ไม่รู้ตลิ่ง/ค่าเพี้ยน/เวลาอนาคต → ไม่นำมาตัดสิน
- แม่น้ำ: เก่ากว่า 3 ชม. → เทา · ไม่มีสถานีสดเลย = "ข้อมูลน้ำเหนือไม่พร้อม" (ไม่ใช่ "ปกติ") · เขื่อน/พระราม 8 เก่ากว่า 6 ชม. = "ค่าเก่า"
- พยากรณ์ฝน: ดึงไม่ได้หรือเก่ากว่า 3 ชม. = "พยากรณ์ไม่พร้อม" — "ไม่มีฝน" แสดงเฉพาะเมื่อพยากรณ์สำเร็จจริง
- เรดาร์: ภาพเก่ากว่า 40 นาที = ไม่พร้อม
- ไฟล์ข้อมูลทั้งไฟล์เก่ากว่า 75 นาที → ทั้งหน้าเป็นเทา "ข้อมูลไม่พอ"

## ข้อจำกัดที่รู้อยู่

- **เว็บ กทม. บล็อกเครื่องต่างประเทศ** (Cloudflare) → บน GitHub ใช้ POPNIX แทน ซึ่งไม่มีสถานีหนองระแหง (126)
  จึงใช้ ค.พระยาสุเรนทร์ ถ.จตุโชติ (125, คลองเดียวกัน ใต้บ้าน 4 กม.) เป็นสถานีบ้านสำรอง
  เครดิต: ข้อมูล: สำนักการระบายน้ำ กรุงเทพมหานคร ผ่าน POPNIX Flood (flood.pop.in.th)
- เว็บขึ้นที่ https://moszasa09-boop.github.io/flood-alert/ ดึงข้อมูลทุก 15 นาที (`.github/workflows/update.yml`)
- GitHub ปิดงานตั้งเวลาอัตโนมัติถ้า repo ไม่มีความเคลื่อนไหว 60 วัน → เข้าไปกด Enable ใน Actions หรือ push อะไรก็ได้

- สถานีที่ชื่อมี `*` ของ กทม. (เช่น คลองหกวา นิมิตใหม่) มักหยุดส่งข้อมูลนานหลายชั่วโมง → ระบบแสดงเป็นเทา
- ThaiWater ส่งค่าทุก 10 นาที แต่บางครั้งกระโดดผิดปกติ (เช่น 1.67 → 1.95 → 1.66) — อัตราขึ้น-ลงคิดจากช่วง 3 ชม. เพื่อลดผลกระทบ
- เรดาร์ RainViewer ฟรี: ย้อนหลัง 2 ชม. ทุก 10 นาที, ละเอียดสุด ~1.2 กม. (ซูม 7), ช้ากว่าจริง ~10 นาที, **ไม่มีพยากรณ์ล่วงหน้า (nowcast)**
- "อาจถึงใน ~X นาที" คำนวณจากระยะกลุ่มฝนใกล้สุดเทียบ 30 นาทีก่อน — คร่าวๆ (อาจเป็นคนละกลุ่มฝน)
- เรดาร์หนองจอก/หนองแขมของ กทม. ห้ามเว็บอื่นดึงภาพ → ทำเป็นปุ่มลิงก์ไปหน้าทางการ
